The root package is a Next.js App Router application (next.config.ts) whose `app/` tree is split across child modules: `storefront_pages` owns the route tree (public storefront, reseller portal, merchant dashboard), while `shared_components` provides the root layout shell, auth flows, cart/wishlist state via global React contexts, and UI primitives consumed by both storefront and dashboard routes. Cross-cutting data contracts live in the root `types.ts` (Product, Order, Reseller, SellerOrderRow, CartItem, etc.) which both the page components and the Supabase RPC clients reference, keeping the frontend shape aligned with the database schema defined in `supabase_migrations`. The Supabase layer exposes SECURITY DEFINER plpgsql functions that the Next.js server-side code calls to perform guest checkout, order lifecycle transitions, analytics aggregation, shipping/payment configuration, and monthly commission wallet/payout operations — decoupling business rules from the React layers.
