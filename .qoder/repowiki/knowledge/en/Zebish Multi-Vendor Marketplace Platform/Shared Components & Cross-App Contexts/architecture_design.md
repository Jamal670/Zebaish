Two top-level React contexts in `components/context/` are the cross-child wiring point: `AuthProvider` (Supabase-backed, resolves `role`, `resellerProfile`, `userProfile`, `sellerStatus`) is consumed by both the storefront pages and the reseller dashboard to gate routes and render role-specific UI; `AppProvider` owns cart, wishlist, mega-menu/search drawer toggles, quick-view product, and toast state, persisted via `localStorage` (`zebaish_cart_items`) and synced to Supabase through `@/src/api/cartWishlistService` once a user is authenticated. The `storefront_shell_and_pages` children consume these contexts directly, while the `reseller/` subtree declares its own isolated contexts (`ResellerContext`, `ListingDraftContext`) layered on top of the shared auth context. All components are Next.js client components (`'use client'`) that import shared types from `@/types` and API hooks from `@/src/hooks` / `@/src/api`, keeping business logic out of the component tree.
