Four top-level Next.js App Router files compose the application shell:
- `layout.tsx` is the root layout: it declares site `Metadata` (title, description, favicon), injects Google Fonts via `<head>` preconnect/link tags, imports `globals.css`, and wraps `children` in a provider stack — `QueryProvider` (TanStack Query) → `AuthProvider` → `AppProvider` → `Analytics` → `MainLayoutShell`.
- `page.tsx` is the client-side home route (`'use client'`) assembling the landing page from feature components (`HeroCarousel`, `NewArrivalsCategories`, `FeaturedCollectionsGrid`, `MostTrending`, `ShopByCollection`, `CoutureSection`, `WornAndLoved`, `Newsletter`) and routing via `next/navigation`'s `useRouter` to `/shop`, `/product/:id`, reseller slugs, and seller dashboard pages.
- `not-found.tsx` renders a branded 404 with links back to `/` and `/shop`.
- `globals.css` is the single CSS entry point: it imports Tailwind v4 (`@import "tailwindcss"`), defines responsive `clamp()` typography tokens under `@theme`, sets base font families (`--font-sans`, `--font-cinzel`, `--font-cormorant`, `--font-script`, Urdu Nastaliq), and adds utility classes `.no-scrollbar` and `.animate-fade-in`.
Dependency direction is one-way outward: this module depends on shared components under `@/components/*`, contexts under `@/components/context/*`, types under `@/types`, and API helpers under `@/src/api/*`; nothing inside the app directory imports back into these leaf files.
