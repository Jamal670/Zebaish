Pages are split by audience: public storefront routes (home, shop, product/[id], cart, checkout, account, auth/callback) live alongside static content pages (about, contact, privacy, terms); a parallel reseller portal (reseller/*) provides login/signup/forgot-password/update-password plus its own dashboard; and a merchant dashboard (dashboard/*) offers admin features like collections, orders, analytics, payouts, reviews, settings, and product variation management. All routes render through the shared `app/layout.tsx` root layout (provided by the `app_root_layout` child), which supplies global providers, fonts, analytics, and the MainLayoutShell so every page inherits the same chrome without re-declaring it.
